# Source Targets

This document gives a practical target for later source collection. The target is quality-focused and realistic for a university project. It avoids excessive collection while still covering the 60 example questions and related semantic variations.

No sources are collected in this document. No URLs or titles are invented.

| Category | Target source count | Reason |
|---|---:|---|
| Department Information | 3-5 | Needs official and authoritative explanation of the field and department identity. |
| Curriculum | 3-5 | Requires current official curriculum/course evidence. |

## Recommended Total

Minimum planned coverage: 56 sources.

Preferred practical target: 65-75 sources.

This range should be enough for a strong RAG knowledge base without making source evaluation and preprocessing too large for the project timeline.

## Highest-Priority Collection Areas

Collect these areas first:

1. Department Information
2. Curriculum
3. Career Opportunities
4. Employment
5. Artificial Intelligence
6. Skills and Technologies
7. Future Technologies
8. Internships

These categories cover the core student questions and the strongest requirements from the university guideline: reliable information, current career relevance, semantic coverage, and source-grounded answers.

## Categories Needing Especially Recent Sources

These areas should prioritize sources from the last one to three years whenever possible:

- Artificial Intelligence
- Cybersecurity
- Employment
- Salaries
- Skills and Technologies
- Future Technologies
- Remote Work
- Career Opportunities
- Specializations

Older sources can be used only when the information is stable, official, or still clearly relevant.
