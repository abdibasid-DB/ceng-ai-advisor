# Source Collection Batch 02

## Stage

Source Collection - Batch 2: Professional, Career, Employment, and Skills Sources

## Project

AI-Powered Computer Engineering Student Advisor

## Date Accessed

2026-08-30

## Scope

This batch strengthens the non-university evidence base for career, employment, internships, skills, specializations, graduate studies, remote work, work-life balance, entrepreneurship, and general Computer Engineering profession questions.

No preprocessing, chunking, embeddings, ChromaDB, Ollama, RAG pipeline, chatbot logic, or application features were implemented in this stage.

## Collection Rules Applied

- Accepted only real and verifiable sources.
- Prioritized professional organizations, government labor data, recognized international organizations, official technical documentation, and reputable industry research.
- Preferred current or recently updated sources when the topic changes quickly.
- Avoided random blogs, SEO content farms, anonymous articles, forums, and unverifiable career pages.
- Used `null` for missing publication dates rather than inventing dates.
- Avoided duplicate sources when a stronger source already covered the same evidence need.
